# Libcobblersignatures [0.2.0](https://github.com/cobbler/libcobblersignatures/tree/v0.2.0) - 2026-08-07

Milestone for this tag: <https://github.com/cobbler/libcobblersignatures/milestone/3>

## Added

- Added basic test coverage for all CLI operations (import, export, edit and
  their submenus)
  [#28](https://github.com/cobbler/libcobblersignatures/issues/28)
- Documented the purpose of every key in the JSON spec, generated from the
  Osversion model docstrings, plus a script (scripts/sync_json_spec_docs.py)
  that keeps the schema and docs in sync with those docstrings.
  [#41](https://github.com/cobbler/libcobblersignatures/issues/41)
- Added native Debian packaging.
  [#47](https://github.com/cobbler/libcobblersignatures/issues/47)
- Added support for various newer distros
  [#57](https://github.com/cobbler/libcobblersignatures/issues/57)
- Added support for older schemas from Cobbler 2.8.x days
  [#63](https://github.com/cobbler/libcobblersignatures/issues/63)
- Added support for Ubuntu 23.10
  [#70](https://github.com/cobbler/libcobblersignatures/issues/70)
- Added Built-In option in import dialog to load the built-in config
  [#73](https://github.com/cobbler/libcobblersignatures/issues/73)


## Changed

- Updated packaging
  [#47](https://github.com/cobbler/libcobblersignatures/issues/47)
- Refactoring for hosting of distro signatures at cobbler.github.io and added
  them to package as data
  [#57](https://github.com/cobbler/libcobblersignatures/issues/57)
- Added support for openSUSE Leap 15.5 and 15.6, Leap Micro, SLES 15SP6 and SLE
  Micro [#67](https://github.com/cobbler/libcobblersignatures/issues/67)
- Added a `libcobblersignatures.exceptions` module with a `SignaturesError`
  hierarchy, and the CLI now prints a friendly message and returns to the menu
  instead of crashing when Import, Export or Edit fails; note that
  `jsontomodels()` now raises `SignaturesValidationError` instead of
  `AttributeError` for a missing rootkey
  [#74](https://github.com/cobbler/libcobblersignatures/issues/74)
- Pinned GitHub Actions to commit SHAs and added Dependabot configuration to
  keep them updated
  [#80](https://github.com/cobbler/libcobblersignatures/issues/80)


## Fixed

- Specified list of valid repo breeds in the signatures schema
  [#69](https://github.com/cobbler/libcobblersignatures/issues/69)
