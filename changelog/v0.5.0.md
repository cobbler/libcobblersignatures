# Libcobblersignatures [0.5.0](https://github.com/cobbler/libcobblersignatures/tree/v0.5.0) - 2026-10-20



## Changed

- Added new releases to v2 and v3: ubuntu 26.04; ubuntu 26.10(released in
  october); opensuse16.1; esxi90; esxi91; freebsd13.3; freebsd13.4;
  freebsd13.5; freebsd14.0; freebsd14.1; freebsd14.2; freebsd14.3; freebsd14.4;
  freebsd14.5; freebsd15.0; freebsd15.1; xenserver830; powerkvm 3.1
  [#79](https://github.com/cobbler/libcobblersignatures/issues/79)


## Fixed

- Updated the Free Software Foundation address in `LICENSE` to its current
  address. [#110](https://github.com/cobbler/libcobblersignatures/issues/110)
- Fixed the `default_autoinstall` value for the Windows `10` and `11` signature
  entries, which incorrectly pointed at a non-existent `built-in-win.ks`
  template instead of the actual shipped `built-in-win.xml` template.
- Fixed the `opensuse16.1` `default_autoinstall` value, which pointed at the
  legacy AutoYaST template (`built-in-sample_autoyast.xml`) instead of the
  JSON-based Agama template (`built-in-autoinst.json`) already used by
  `opensuse16.0`.
- Fixed the `resolute` (Ubuntu 26.04) `default_autoinstall` value, which was
  empty, the same regression already present in `questing`.
