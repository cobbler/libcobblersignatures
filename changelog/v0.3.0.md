# Libcobblersignatures [0.3.0](https://github.com/cobbler/libcobblersignatures/tree/v0.3.0) - 2026-08-07

## Added

- Added a `v3` schema/data set (`data/v3/`), identical to `v2` except every
  non-empty `default_autoinstall` value is prefixed `built-in-`, matching how
  Cobbler registers its bundled autoinstall templates. `ImportTypes.BUILT_IN`
  now loads this `v3` data instead of `v2`.
  [#87](https://github.com/cobbler/libcobblersignatures/issues/87)
